# Непрерывное тестирование DEMO

Пользователь разрешил 3 октября 2026 убрать ограничения по потерям на DEMO,
чтобы продолжать тестирование стратегий. Разрешение относится к восстановлению
торговли сейчас и сохранению настройки после перезапуска.

Используем отдельный флаг `DEMO_CONTINUOUS_TESTING`, по умолчанию false.
При true дневной лимит потерь, предел серии убыточных сделок и loss cooldown
не блокируют новые входы. Флаг разрешён только при `TRADING_MODE=demo`;
другие режимы сохраняют существующее поведение. Большие фиктивные числовые
лимиты не подходят, потому что могут снова остановить тестирование.

Статистика PnL, сохранённое состояние риска и история сделок продолжают
обновляться. Проверки доступности equity, корректности счёта, ордеров,
позиции и рыночных данных сохраняются, как и ручная пауза, размеры сделок,
лимит параллельных позиций и фильтры стратегии. Непрерывное тестирование означает
отсутствие остановок по результату сделок, а не принудительные входы без сигнала.

HTTP /status и Telegram /status показывают, включены ли лимиты потерь.
При обновлении серверной версии сохраняются серверные SQLite и конфигурация;
в env меняется только новый флаг. Оператор снимает текущую сохранённую причину
`daily loss limit` после проверки аккаунта, без сброса статистики или иных причин.

Проверки: отсутствие блокировки после большого убытка и серии потерь,
сохранение статистики после восстановления, сохранение технических блокировок,
изоляция от LIVE/TESTNET/PAPER, полный набор тестов, сборка и наблюдение
сверок аккаунта после установки на сервер.
