# Сервер проекта

Данные предоставлены пользователем 2026-10-03; SSH-подключение проверено.

- SSH: `ssh root@81.163.27.15`.
- Имя хоста: `violent-glaramara`, регион MSK.
- Ubuntu 22.04 64-bit; 1 CPU, 1 ГБ RAM, 30 ГБ SSD (по панели сервера).
- Бот: systemd-служба `trad-baybit`, пользователь службы `bybit-bot`.
- Приложение: `/opt/trad-baybit/app`; запуск: `/opt/trad-baybit/launch.sh`.
- Конфигурация: `/etc/trad-baybit/demo.env`.
- Рабочая директория и SQLite: `/var/lib/trad-baybit`, `/var/lib/trad-baybit/demo.db`.
- Read-only HTTP API: `http://127.0.0.1:3004/api/status` на сервере.
- Журнал: `journalctl -u trad-baybit`; время журнала сервера UTC, МСК = UTC+3.
- Проверенный режим: Bybit DEMO, виртуальные средства.

На сервере также размещены другие сайты и футбольный бот. При обновлении торгового
бота сохранять серверную SQLite и конфигурацию; не заменять их локальными снимками.
Не хранить пароли, приватные SSH-ключи и API-секреты в этой памятке.
